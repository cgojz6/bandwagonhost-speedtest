## 搬瓦工测速的本质是什么

先把概念讲清楚。**BandwagonHost speed test**（搬瓦工测速）其实包含两件完全不同的事情：

**第一种**：在买 VPS 之前，你想知道某个机房跟你本地网络的延迟和速度，帮助你选机房。这用的是搬瓦工官方每个机房提供的 LookingGlass 测速站，直接在浏览器里跑，不需要买任何东西。

两件事目的不同，工具也不同。下面分开说。

## 买了之后：对 VPS 做 benchmark

这里讲的是你已经有了搬瓦工的 VPS，想测服务器本身性能。

### 方法一：用 speedtest-cli 测网络带宽

bash
# 安装
sudo apt install speedtest-cli

# 跑测试
speedtest


这会显示你的 VPS 到最近 speedtest 服务器的上下行速度。数字好看不代表一切——关键是看你 VPS 到目标用户的速度，所以建议指定测试服务器。

### 方法二：用 iperf3 测真实吞吐量

bash
sudo apt install iperf3

# 在你的 VPS 上开服务端
iperf3 -s

# 从本地机器连接测试
iperf3 -c 你的VPS_IP -t 30


这个数字才是你和服务器之间真实的传输速率，比 speedtest 更有参考价值。

### 方法三：一键 benchmark 脚本

这是最省事的方式。搬瓦工专属测速脚本（来自 github.com/devguoo/bwg-speed-test）可以一次性 ping 所有搬瓦工机房，告诉你哪个延迟最低：

bash
curl -fsSL https://raw.githubusercontent.com/devguoo/bwg-speed-test/main/test.sh | bash


跑完会输出类似这样的结果（实际数值因你的服务器位置不同而变化）：


香港 HK85       30.2 ms  ● Great
日本大阪软银     65.3 ms  ● Great
DC6 CN2 GIA-E   148.2 ms ● Good
DC9 CN2 GIA     155.1 ms ● Good
DC3 CN2         152.3 ms ● Good
荷兰 EUNL_9     190.5 ms ● Fair


这个脚本对**已购买搬瓦工并想选最优迁移目标**的用户特别有用。延迟最低的就是最适合你当前服务器网络环境的机房。

## CN2 GIA 和 CN2 GT 的区别，一次说清楚

很多人第一次看到这两个词脑子里转圈。说白了就是这么回事：

**CN2 GT（Global Transit）**：这是 CN2 线路的普通版，骨干节点只有少部分走 59.43 前缀的高质量路由，其余走的还是普通 202.97 节点。晚高峰的时候有拥塞风险。

**CN2 GIA（Global Internet Access）**：全程走 59.43 高质量路由，从中国出口到目的地，整条路都是优先级最高的通道。晚高峰表现明显比 GT 稳定，不容易出现速度骤降。

从 sites.google.com/view/teaching-with-tara 上一位用户对 CN2 GIA 的连续监测来看，即便在中国晚高峰期间，CN2 GIA 的速度依然保持稳定，没有明显波动——这正是 GIA 比 GT 贵的原因所在。

所以：如果你只是偶尔用、对延迟不敏感，CN2 GT 的 $49.99/年完全够用。如果你有稳定需求，或者经常在晚上用，CN2 GIA-E 更划算。
